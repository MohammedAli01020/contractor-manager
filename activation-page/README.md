# صفحة تفعيل مدير الشركة

الطريقة المعتمدة حاليًا هي تقديم صفحة التفعيل من نفس تطبيق Spring Boot المستضاف على Railway، حتى تكون الصفحة والـ API على نفس النطاق ولا نحتاج إلى إعداد CORS أو استضافة ثابتة منفصلة.

ملفات الصفحة المستخدمة في الإنتاج موجودة في:
`backend/src/main/resources/static/activate-admin/`

بعد نشر تحديث التطبيق على Railway، افتح:
`https://YOUR-SERVICE.up.railway.app/activate-admin/index.html`

استبدل `YOUR-SERVICE` بالنطاق العام الحقيقي لخدمتك. واضبط خاصية الخادم `app.platform.activation-base-url` على نفس الرابط الكامل أعلاه؛ الـ Backend سيضيف رمز التفعيل إلى الرابط عند إنشاء مدير جديد.

مجلد `activation-page/` هو النسخة المستقلة القديمة للاحتفاظ بها كخيار بديل، وليس مطلوبًا نشره على Cloudflare عند استخدام طريقة Railway.

## ملاحظات أمنية

- لا تضع أسرار الخادم أو بيانات دخول في ملفات الواجهة؛ كل ما في هذه الملفات عام ويمكن لأي زائر قراءته.
- لا تشارك رابط التفعيل إلا مع الأدمن المقصود؛ الرمز مؤقت ويستخدم مرة واحدة.
- فعّل HTTPS، ولا تسجل الرمز أو كلمة المرور في سجلات الواجهة أو الخادم.
- اختبر رابطًا صالحًا، ورابطًا منتهيًا، ورمزًا مستخدمًا سابقًا قبل الاعتماد على الميزة.
